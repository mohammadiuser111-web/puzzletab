# پازل‌تب (PuzzleTab) — نسخهٔ ۲

ابزار **ساکن در System Tray ویندوز** (کنار ساعت) که پنجره‌های **واقعیِ باز** روی دسکتاپت (تلگرام دسکتاپ، کروم، دیسکورد، هر برنامه‌ای) را مثل **پازل** می‌چیند — بدون این‌که یک «برنامهٔ جدا» با هدر و نوار ابزار دائمی باشد. هیچ پنجرهٔ اصلی‌ای همیشه باز نیست؛ همه‌چیز از آیکون تری کنترل می‌شود.

> ⚠️ این یک تغییر بزرگ نسبت به نسخهٔ قبلی است: نسخهٔ قبلی سایت‌ها را **داخل خودِ برنامه** (با `webview`) نشان می‌داد. این نسخه پنجره‌های **واقعی ویندوز** را جابه‌جا/تغییر اندازه می‌دهد. نسخهٔ قبلی هم هنوز از تری در دسترسه («حالت کاشی‌های داخلی»).

## این ابزار فقط و فقط روی ویندوز کار می‌کند

چون از APIهای بومی ویندوز (`user32.dll`, `dwmapi.dll` از طریق یک اسکریپت PowerShell) برای شمارش/جابه‌جایی/زوم پنجره‌ها استفاده می‌کند. **من این بخش را روی یک محیط لینوکسی ساختم و نمی‌توانم آن را روی ویندوز واقعی اجرا/تست کنم** — منطق را با یک «بک‌اند آزمایشی» شبیه‌سازی‌شده کاملاً تست کردم (کشیدن/تغییراندازه/محاسبهٔ زوم/جابه‌جایی همه درست کار می‌کنند)، اما خودِ تماس‌های Win32 را فقط روی ویندوز واقعی می‌شود دید. **لطفاً بعد از نصب روی سیستم خودت امتحانش کن و هر چی کار نکرد را برام بگو تا سریع درستش کنم.**

## چطور کار می‌کند

1. از آیکون تری → **«چیدمان پنجره‌های باز…»** → لیست پنجره‌های بازِ فعلی‌ات می‌آید (عنوان + آیکون برنامه)، هر چند تا خواستی تیک بزن.
2. یک لایهٔ شیشه‌ای روی کل صفحه باز می‌شود؛ هر پنجرهٔ انتخابی به‌صورت یک کاشی نشان داده می‌شود، دقیقاً سرجای فعلی خودش.
3. کاشی‌ها را مثل پازل بکش/تغییر اندازه بده. **همین که دستت را از ماوس برداری (رها کنی)، پنجرهٔ واقعی همان لحظه جابه‌جا/تغییر اندازه می‌شود.**
4. برای پنجره‌های **مرورگر** (کروم/اج/فایرفاکس) یک افت‌داون «اندازهٔ ۱۰۰٪» روی کاشی هست (پیش‌فرض ۱۲۸۰px). وقتی کاشی را کوچک می‌کنی، پازل‌تب خودش زوم آن پنجره را (با فرستادن کلیدهای Ctrl+- /Ctrl+0 به همان پنجره) کم می‌کند تا طوری که محتوای سایت **در حالت دسکتاپِ ۱۰۰٪ بماند، فقط کوچک‌تر دیده شود** — دقیقاً مثل خودت که در یک پنجرهٔ بزرگ‌تر زوم می‌کنی بیرون.
5. `Esc` یا دکمهٔ «پایان» در نوار شناور بالا، حالت ویرایش را می‌بندد. پنجره‌ها همان‌جا که گذاشتی‌شان می‌مانند.
6. از تری → **«اعمال آخرین چیدمان»** هر وقت (مثلاً بعد از ری‌استارت ویندوز و باز کردن دوباره‌ی برنامه‌ها) می‌تونی با یک کلیک همون چیدمان رو دوباره بچینی.

## محدودیت‌های مهم (صادقانه بگم)

- **زوم خودکار فقط برای مرورگرها (Chrome / Edge / Firefox / Brave / Opera / Vivaldi)** فعال می‌شود؛ برنامه‌های دسکتاپ معمولی (تلگرام دسکتاپ، دیسکورد، اسپاتیفای، ...) اصلاً مشکل «حالت موبایل» ندارند، پس زوم رویشان اعمال نمی‌شود — فقط جابه‌جا/تغییر اندازه می‌شوند.
- زوم مرورگر با شبیه‌سازی کلید میانبر زده می‌شود و **فقط روی تبِ فعلیِ آن پنجره** اثر می‌گذارد. بهترین نتیجه وقتی‌ست که هر پنجرهٔ مدیریت‌شده را به یک سایت/تبِ مشخص اختصاص بدهی (مثلاً یک پنجرهٔ کروم جدا فقط برای تلگرام وب).
- چون زوم مرورگر در پله‌های استاندارد (۲۵٪،۳۳٪،۵۰٪...۱۰۰٪...) است، نتیجه **تقریبی** است نه دقیقاً برابر با نسبت اندازه؛ پازل‌تب نزدیک‌ترین پله را انتخاب می‌کند.
- گوگل/جیمیل معمولاً ورود (OAuth) را داخل مرورگرهای خودکارشده مسدود می‌کند؛ این محدودیتِ خودِ گوگل است، نه پازل‌تب.
- شناساییِ پنجره‌ها یک الگوریتم استاندارد ویندوزی است (شبیه آنچه Alt+Tab استفاده می‌کند) ولی ممکن است بعضی برنامه‌های خاص (مخصوصاً اپ‌های UWP از Microsoft Store) درست شناسایی نشوند؛ اگر دیدی پنجره‌ای در لیست نبود بهم بگو.

## نصب

توی پوشهٔ `release/`:
- `PuzzleTab-Setup-1.0.0.exe` — نصب‌کننده (میانبر می‌سازد)
- `PuzzleTab-Portable-1.0.0.exe` — بدون نصب

بعد از اجرا، **پنجره‌ای باز نمی‌شود** — فقط یک آیکون 🧩 کنار ساعت ویندوز (System Tray) ظاهر می‌شود؛ همان‌جا راست‌کلیک کن.

میانبر سراسری `Ctrl+Alt+P` هم لایهٔ چیدمان را باز/بسته می‌کند.

## منوی تری

| گزینه | کار |
|---|---|
| 🧩 چیدمان پنجره‌های باز… | انتخاب پنجره‌ها و باز کردن لایهٔ ویرایش |
| ↻ اعمال آخرین چیدمان | چیدمان ذخیره‌شدهٔ قبلی را دوباره روی پنجره‌های هم‌نام اعمال می‌کند |
| 🔍 بازنشانی زوم مرورگرها | زوم همهٔ مرورگرهای مدیریت‌شده را به ۱۰۰٪ برمی‌گرداند |
| 🗂 حالت کاشی‌های داخلی | همان نسخهٔ قبلی: چند سایت داخل یک پنجرهٔ برنامه (نه پنجره‌های واقعی) |
| اجرا هنگام ورود به ویندوز | روشن/خاموش کردن اجرای خودکار |
| خروج از پازل‌تب | کامل بستن برنامه (آیکون از تری هم می‌رود) |

## ساخت از سورس

```bash
npm install
npm start                 # اجرا (بدون پنجره؛ از تری استفاده کن)
npm run selftest          # تست خودکار حالت «کاشی‌های داخلی»
npm run selftest:overlay  # تست خودکار منطق Overlay (با بک‌اند آزمایشی، روی هر سیستمی اجرا می‌شود)
npm run dist               # ساخت Setup.exe + Portable.exe در release/
```

روی غیرِ ویندوز (یا هنگام توسعه)، `winctl.js` خودش به‌صورت خودکار از یک **بک‌اند آزمایشی حافظه‌ای** به‌جای PowerShell واقعی استفاده می‌کند (برچسب «حالت آزمایشی» در منوی تری دیده می‌شود) — همین باعث شد بتوانم کل منطق کشیدن/تغییراندازه/محاسبهٔ زوم را بدون ویندوز هم تست کنم.

## فایل‌های کلیدی

- `main.js` — تری، پنجره‌های Picker/Overlay، IPC
- `winctl.js` — پل بین Electron و PowerShell (یا بک‌اند آزمایشی)
- `winhelper/winhelper.ps1` — اسکریپت PowerShell که واقعاً پنجره‌های ویندوز را می‌شمارد/جابه‌جا/زوم می‌کند
- `renderer/picker/` — دیالوگ انتخاب پنجره‌ها
- `renderer/overlay/` — لایهٔ شیشه‌ایِ چیدمان پازلی
- `renderer/` (فایل‌های ریشه) — حالت قدیمیِ «کاشی‌های داخلی»
