# پازل‌تب (PuzzleTab)

اپلیکیشن ویندوزی با ظاهر **Fluent / Windows 11** برای اینکه چند سایت (تلگرام وب، آپارات، یوتیوب، ...) را هم‌زمان در یک پنجره، کنار هم مثل **پازل** بچینی — بدون اینکه سایت‌ها به حالت موبایل/ریسپانسیو بیفتند، حتی وقتی خیلی کوچک شده باشند.

## ترفند فنی (چرا سایت‌ها موبایل نمی‌شوند؟)

هر کاشی یک `<webview>` مستقل (مرورگر کروم کاملاً جدا، نه iframe) است. وقتی کاشی را کوچک می‌کنی، به‌جای کوچک‌کردن **عرض واقعی صفحه**، از زوم‌اوت کروم استفاده می‌کنیم: عرض کاشی را تقسیم بر ضریب زوم می‌کنیم تا «عرض منطقی» صفحه (همون چیزی که مدیا-کوئری‌های CSS بهش نگاه می‌کنند) همیشه برابر با یک مقدار دسکتاپی (مثلاً ۱۲۸۰ پیکسل) بماند. یعنی اگر کاشی را به ۴۰٪ اندازه‌اش کوچک کنی، سایت هنوز فکر می‌کند روی مانیتور ۱۲۸۰ پیکسلی باز شده، فقط خروجی‌اش کوچک‌نمایی شده — دقیقاً مثل خودِ تو. از منوی «بیشتر» روی هر کاشی می‌توانی این «عرض مجازی» را دستی هم عوض کنی (۱۹۲۰، ۱۵۳۶، ۱۲۸۰، ۱۰۲۴، تبلت یا حتی موبایل واقعی برای تست).

نکتهٔ جانبی: چون `<webview>` یک فرایند جدا و مستقل است (نه iframe)، محدودیت‌های معروف «این سایت اجازهٔ قاب‌شدن نمی‌دهد» (X-Frame-Options) که باعث میشه خیلی سایت‌ها داخل iframe باز نشن، اینجا اصلاً اعمال نمی‌شود.

## امکانات

- **چیدمان پازلی آزاد**: کاشی‌ها را بکش، گوشه‌هاشان را بکش تا تغییر اندازه بدن؛ به لبهٔ هم و لبهٔ پنجره می‌چسبند (چسبیدن را می‌توانی از نوار بالا خاموش/روشن کنی).
- **نشست جدا برای هر کاشی**: هر کاشی کوکی/لاگین مستقل خودش را دارد — یعنی می‌توانی مثلاً دو حساب تلگرام یا جیمیل متفاوت را هم‌زمان در دو کاشی باز نگه داری. از منوی «بیشتر» می‌توانی نشست یک کاشی را هم کامل پاک کنی (خروج از حساب).
- **ذخیرهٔ خودکار چیدمان**: با بستن و بازکردن اپ، همان کاشی‌ها و همان چیدمان برمی‌گردد. هنگام تغییر اندازهٔ پنجره هم همهٔ کاشی‌ها به‌نسبت با هم بزرگ/کوچک می‌شوند (مثل اسنپ‌لایوت ویندوز).
- **چیدمان‌های آماده و دلخواه**: از دکمهٔ «چیدمان» یک‌ستونه/دوستونه/سه‌ستونه/شبکه‌ای/آبشاری بگیر، یا چیدمان دلخواهت را با اسم دلخواه از «چیدمان‌های من» ذخیره و بعداً برگردان.
- **میانبرهای آماده**: تلگرام وب، آپارات، یوتیوب، واتساپ وب، اینستاگرام، ایکس/توییتر، دیسکورد، چت‌جی‌پی‌تی — یا هر نشانی دلخواه دیگر.
- **سازگار با ویندوز ۱۱**: روی ویندوز ۱۱ پس‌زمینهٔ Mica واقعی سیستم را می‌گیرد، رنگ تم (تیره/روشن) و رنگ اکسنت را از ویندوز می‌خواند.
- **همیشه روی صفحه** و **میانبر سراسری `Ctrl+Alt+P`** برای نمایش/مخفی‌کردن سریع پنجره از هر جای ویندوز.

## نصب روی ویندوز

دو فایل در پوشهٔ `release/` ساخته شده:

- `PuzzleTab-Setup-1.0.0.exe` — نصب‌کنندهٔ معمولی (میانبر دسکتاپ/استارت‌منو می‌سازد).
- `PuzzleTab-Portable-1.0.0.exe` — نسخهٔ پرتابل، بدون نصب، کافیه اجرا کنی.

> چون این برنامه امضای دیجیتال رسمی (کد-سایمینگ) ندارد، ممکن است ویندوز اسمارت‌اسکرین هشدار «ناشر ناشناس» نشان بدهد؛ روی «اطلاعات بیشتر → اجرا در هر صورت» بزن.

## استفاده

1. روی **«+ افزودن کاشی»** بزن، نشانی سایت را بنویس (یا یکی از میانبرهای رایج را بزن) و اندازهٔ نمای دسکتاپش را انتخاب کن.
2. کاشی را از نوار عنوانش بکش و جابه‌جا کن؛ از گوشه/لبه‌هایش بکش تا اندازه‌اش را عوض کنی.
3. چند بار این کار را تکرار کن تا پازل دلخواهت ساخته شود (مثلاً یک‌طرف تلگرام، یک‌طرف آپارات، دو کاشی از یک سایت در دو تب).
4. از **«چیدمان»** برای مرتب‌سازی خودکار و از **«چیدمان‌های من → ذخیرهٔ چیدمان فعلی»** برای ذخیرهٔ چیدمان‌های پرکاربردت استفاده کن.
5. دابل‌کلیک روی نوار عنوان یک کاشی = بیشینه/بازگردانی آن کاشی.

## محدودیت‌های شناخته‌شده

- **گوگل/جیمیل**: گوگل ورود (OAuth) را داخل مرورگرهای جاسازی‌شده (مثل این اپ، یا هر اپ الکترونی دیگری) مسدود می‌کند و پیام «این مرورگر یا برنامه ممکن است امن نباشد» می‌دهد. برای جیمیل/گوگل بهتره از دکمهٔ «باز کردن در مرورگر پیش‌فرض» در منوی کاشی استفاده کنی.
- چون هر کاشی نشست جدا دارد، اگر همان سایت را در دو کاشی باز کنی، باید در هر دو جدا لاگین کنی (این یک محدودیتِ عمدی و برای جلوگیری از تداخل زوم بین کاشی‌های هم‌دامنه است؛ در عوض امکان باز نگه‌داشتن چند حساب هم‌زمان از یک سایت را می‌دهد).

## ساخت از سورس (در صورت نیاز به تغییر)

```bash
npm install
npm start          # اجرای مستقیم برای تست
npm run dist        # ساخت نصب‌کننده + نسخهٔ پرتابل ویندوز در پوشهٔ release/
```

نیازمندی: Node.js نسخهٔ ۲۰ به بالا. ساخت خروجی ویندوز را می‌توان هم روی ویندوز و هم روی لینوکس (با Wine نصب‌شده) انجام داد.
